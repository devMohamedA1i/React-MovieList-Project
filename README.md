# React Movie List

A responsive movie browsing interface built with React components, props, and modern CSS.

## Tech Stack

- JavaScript, React, CSS3

## Structure

```text
├── public/

```

## Getting Started

```bash
git clone https://github.com/devMohamedA1i/React-MovieList-Project.git
cd React-MovieList-Project
npm install
npm run start
```
